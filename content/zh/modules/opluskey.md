## 概述

一加（OnePlus）设备上的物理三段式开关以及 OPPO/Realme 新机型上的可自定义实体侧键，带来了极佳的盲操物理手感。然而，原生 ColorOS 与 OxygenOS 将这些按键限制在预设的声音模式或少数快捷助手功能上，无法充分发挥硬件潜力。

由 ItosEO 开发的 **OplusKey** 是一款使用 C++ 编写的轻量级高性能 Root 模块。它直接从 Linux 内核的 `/dev/input/` 事件节点拦截硬件输入流，支持用户将三段式滑块与自定义实体按键重新绑定为任意 Shell 脚本或系统动作。

## 核心能力

1. **经典三段式开关**：
   - 实时监听滑块在上、中、下三档位置之间的状态切换。
   - 自动抑制原厂系统的声音模式切换横幅，让你自由将三段式滑块改造为专属开关（例如切换省电模式、隐私模式或屏幕方向锁定）。
2. **新款多动作实体侧键**：
   - 支持识别丰富的连击节奏：单击、双击、三击与长按。
3. **超低功耗 C++ 架构**：
   - 编译后的原生守护进程采用非阻塞事件流监听机制，并将 CPU 线程亲和性严格固定在单个能效小核上，日常续航损耗几乎可以忽略不计。

## 配置与使用

模块内置了示例 Shell 脚本，你可根据个人使用习惯自由定制：
- **常用动作**：开关手电筒、启停蓝牙、切换 NFC 状态、后台启动录音或开始屏幕录制。
- 对于配备新款自定义侧键的机型，请在 ColorOS/OxygenOS 系统设置中将该按键的默认动作设为 **无动作**，以便交由 OplusKey 的原生监听进程接管全部输入事件。

## 安装指南

1. 从 GitHub Releases 下载最新版的 `OplusKey-*.zip` 安装包。
2. 在 **Magisk** 中刷入该模块。
3. 重启设备。
4. 进入模块目录下的脚本目录，按需修改触发动作即可适配你的日常工作流。
