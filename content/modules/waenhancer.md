## Overview

**WaEnhancer** (`Dev4Mod/WaEnhancer`, package `com.wmods.wppenhacer`) is an open-source Xposed module designed to extend **WhatsApp** (`com.whatsapp`) and **WhatsApp Business** (`com.whatsapp.w4b`) with advanced privacy, messaging, and visual customization features.

Unlike legacy WhatsApp "modded APKs" that require uninstalling the official Play Store app and trusting re-signed third-party binaries, WaEnhancer operates **entirely in runtime memory** via **LSPosed** without tampering with the original WhatsApp APK on disk.

> **Important Warning & Legal Scope**: WaEnhancer is published for educational research only. Upstream explicitly notes that it contains zero proprietary Meta/WhatsApp code and distributes no modified WhatsApp APKs. Modifying client behavior carries an inherent risk of temporary or permanent WhatsApp account bans—use at your own risk.

## Technical Architecture & How It Works

### YukiHookAPI + libxposed API 101 + DexKit

Inspecting `WaEnhancer-1.6.6.0352170C.apk` (`1.6.6-0352170c`) reveals a modern multi-layer hooking stack:

1. **Xposed & YukiHook Entrypoint**:
   - `META-INF/xposed/module.prop` targets **libxposed API 101** (`minApiVersion=101`, `targetApiVersion=101`, `staticScope=false`) generated by **YukiHook 1.5.0**, with Java entrypoint `com.wmods.wppenhacer.WppXposed_YukiHookXposedInit`.
   - The app integrates `com.wmods.wppenhacer.XposedService`, `io.github.libxposed.service.XposedProvider`, `PrefsProvider`, and `HookProvider` / `BridgeService` to push preference changes cleanly into hooked processes.
2. **Dynamic DEX Resolution (`libdexkit.so`)**:
   - Because WhatsApp heavily obfuscates class and method names on every release, WaEnhancer ships native `libdexkit.so` (`arm64-v8a` and `armeabi-v7a`) to locate target hooks via bytecode signatures rather than brittle hardcoded names.
   - It also includes `libaudio_opus_converter.so` for audio format handling.
3. **Target Scope (`META-INF/xposed/scope.list`)**:
   - Declares `com.whatsapp` (WhatsApp), `com.whatsapp.w4b` (WhatsApp Business), and `system`.
4. **Customization Tooling**:
   - Bundles an interactive web-based CSS editor (`assets/css_editor.html` with Prism syntax highlighting in `assets/www/`) and dedicated activities such as `CallRecordingSettingsActivity`.

## Installation & Setup

1. Ensure you have **WhatsApp** (`com.whatsapp`) or **WhatsApp Business** (`com.whatsapp.w4b`) installed from an official source, along with **LSPosed** (API 101).
2. Download `WaEnhancer-1.6.6.0352170C.apk` from `Dev4Mod/WaEnhancer` releases and install it:
   ```bash
   adb install WaEnhancer-1.6.6.0352170C.apk
   ```
3. Open **LSPosed Manager** -> **Modules**, enable **WaEnhancer**, and ensure `com.whatsapp` (and/or `com.whatsapp.w4b`) is selected in Scope.
4. Open the **WaEnhancer** app (`MainActivity`), grant storage/notification permissions if prompted for media/backup features, configure your desired privacy and UI toggles, and force-stop/restart WhatsApp (or use `ForceStartActivity` inside the module).

## Troubleshooting & Best Practices

- **Hooks stop working after a WhatsApp update**: Open WaEnhancer to trigger a fresh DexKit cache rebuild, or check `Dev4Mod/WaEnhancer` releases for updated signature rules matching the newest WhatsApp version.
- **Crashes on launch**: Disable experimental toggles one by one or clear the DexKit/module cache and force-stop WhatsApp before relaunching.
