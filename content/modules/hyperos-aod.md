## Overview

Xiaomi's HyperOS introduces a redesigned lock screen customization engine and dynamic Always-On Display (AOD) effects. However, Xiaomi artificially gates many of these flagship features—such as depth effect wallpapers, 10-second AOD display overrides, and advanced typographic clock styles—restricting them exclusively to high-end flagship models.

Maintained by developer Kashi through Mods-Center, **HyperOS-AOD** is a systemless modification that replaces the stock `com.miui.aod` package with a fully unlocked, enhanced variant. It brings flagship-tier lock screen editing and unrestricted Always-On Display functionality to any Xiaomi, Redmi, or POCO device running HyperOS.

## Unlocked Capabilities

- **Depth Effect Wallpaper Engine**: Position lock screen clock fonts behind portrait subjects, landscape silhouettes, and custom wallpaper layers.
- **Full Lock Screen Customization**: Access the full range of classic, rhombic, and magazine lock screen templates previously hidden on lower-tier hardware.
- **Unrestricted AOD Clock Displays**: Choose from an expanded catalog of analog dials, digital clocks, signatures, and ambient status widgets.
- **Refined Display Transitions**: Eliminates abrupt brightness jumps and stutter when transitioning from the dimmed AOD state to the illuminated lock screen.

## Installation & Prerequisites

On Android 14 and newer HyperOS ROMs, Xiaomi enforces strict system package signature verification that prevents modified system APKs from loading:

1. **Prerequisite**: If you are running Android 14+ (Global, EEA, or China ROM), install the **Apk Protection Patch** or have **Core Patch** active in LSPosed.
2. Download the latest `HyperOS_AOD_V*.zip` from the project's GitHub releases.
3. Open **Magisk** or **KernelSU**, install the zip from local storage, and reboot.
4. Long-press on your lock screen to launch the enhanced Lock Screen Editor, or navigate to **Settings > Always-on display & Lock screen** to customize your display.
