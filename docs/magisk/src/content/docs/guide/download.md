## Official Download

:::caution[Always Download from Official Sources]
Never download Magisk from unauthorized third-party websites or untrusted stores, as repackaged APKs may contain malicious code. Always use John Wu's official GitHub releases.
:::
- **Official GitHub Releases (Primary)**: [topjohnwu/Magisk Releases](https://github.com/topjohnwu/Magisk/releases)
- **Direct Latest Stable APK**: Download the latest `Magisk-vXX.X.apk` listed under the **Assets** section of the latest release.

---

## Beginner Guide: How to Download from GitHub

If you are new to GitHub:
1. Open the [Magisk Releases page](https://github.com/topjohnwu/Magisk/releases).
2. The topmost release marked with a green **Latest** tag is the most stable version.
3. Scroll down to the **Assets** section at the bottom of that release entry.
4. Click on `Magisk-vXX.X.apk` (for example, `Magisk-v28.1.apk`) to download it directly to your phone or computer.
5. On your phone, tap the downloaded APK in your file manager and tap **Install** (enable "Install unknown apps" if prompted by Android).

## Release Channels & Variants

- **Official Magisk (Stable)**: Recommended for daily use and maximum reliability.
- **Official Magisk (Beta / Canary)**: Contains cutting-edge bug fixes and new Android version compatibility before public stable release.
- **Kitsune Mask (formerly Magisk Delta)**: A popular community fork with built-in SuList, specifically designed for users needing advanced root isolation against detection.
