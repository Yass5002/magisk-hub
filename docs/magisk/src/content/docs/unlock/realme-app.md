:::note[Overview]
Realme requires an official In-Depth Test application token to permit Bootloader unlocking. Different Realme models and OS versions require specific APK versions.
:::

## How to Use
1. Install the matching APK for your device model.
2. Tap **Apply for In-Depth Test**, read the disclaimer, and submit.
3. Review approval generally takes up to 1–3 business days.
4. Once status says "Approved", tap **Start In-Depth Test** to reboot straight into Fastboot mode and run `fastboot flashing unlock`.

---
