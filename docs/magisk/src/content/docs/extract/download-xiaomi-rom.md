## Recommended Methods

### Method 1: System Updater (Recommended)
1. Go to **Settings – My Device – System Update** (or HyperOS version card).
2. Tap the three dots in the upper-right corner.
3. Select **Download latest full package**.
4. Once download starts past 1%, pause it if you wish to download on PC, or let it finish.
5. The downloaded file is stored in `Internal Storage/download_rom/`.

### Method 2: Official Web Repositories
- Official & Community ROM Repositories: [XiaomiROM](https://xiaomirom.com/en/) or [Xiaomi Community](https://new.c.mi.com/)
- Search by device codename (e.g., `houji`, `mondrian`, `cupid`, etc.) to get Fastboot or Recovery TGZ/ZIP packages.
