:::note[Important Note]
- In theory, all Android devices can be flashed as long as the **Bootloader** can be unlocked.
- **General Workflow:** `Unlock Bootloader` > `Patch boot.img` > `Fastboot flash patched image`.
- For models with kernel versions `5.15.XX` - `6.X.XX`, see the [Xiaomi init_boot Guide](/magisk/install/xiaomi-init-boot).
- Universal tutorial for Xiaomi, Redmi, HyperOS, and MIUI.
:::

## Demonstration Environment
- **Device Model:** Xiaomi 10 Pro
- **System Version:** MIUI 14 (Android 13)

## Demonstration Steps

### 1. Unlock Bootloader
Unlock your device's Bootloader: [Xiaomi BL Unlock Guide](/magisk/unlock/xiaomi).  
*(If your phone cannot unlock BL, try [LightSpeed Virtual Machine](/magisk/install/virtual-machine) to run Magisk without unlocking BL).*

### 2. Extract `boot.img`
Extract `boot.img` from your device's official ROM package using [payload-dumper-go boot.img](/magisk/extract/payload-dumper-boot).  
*(If your system package already contains `boot.img`, you can skip this step).*

### 3. Copy `boot.img` to Phone
Connect phone to PC in **File Transfer (MTP)** mode, and copy `boot.img` into your phone's `Download` directory.

### 4. Install Magisk App
Download and install Magisk on your phone: [Download Magisk](/magisk/guide/download).

### 5. Patch `boot.img`
Open Magisk:
1. Tap **Install**
2. Choose **Select and Patch a File**
3. Select `boot.img`
4. Tap **LET'S GO** to begin patching
5. The generated file `magisk_patched-xxx.img` is saved in the `Download` folder.

![Patching boot.img in Magisk](/images/a1bd2ef6dbcc0ef.jpg)
*Patching boot.img in Magisk*


### 6. Download Platform-Tools on PC
Download official [Google Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) and extract it using [7-Zip](https://www.7-zip.org/).

:::tip[Beginner Terminal Tip]
Open the extracted `platform-tools` folder in Windows File Explorer, click directly on the address bar at the top, type `cmd`, and press **Enter**. This opens Command Prompt directly in the tools directory.
:::
![Extracting adb-fastboot](/images/02e5e0821c8cb55.png)
*Extracting adb-fastboot*


### 7. Copy Patched File to PC
Connect the phone to PC in **File Transfer** mode, open the `Download` folder, and copy `magisk_patched-xxx.img` to the PC's `adb-fastboot` directory.

![Copying patched boot image to adb-fastboot folder](/images/bdb4e2a5c4bfb97.png)
*Copying patched boot image to adb-fastboot folder*


### 8. Enter Bootloader Mode
Put the phone into **Bootloader mode**:
- Turn off the phone.
- Press and hold **Power + Volume Down** simultaneously.
- Connect the phone to your PC via USB cable.

![Xiaomi Bootloader mode](/images/5617427dce0c230.png)
*Xiaomi Bootloader mode*


### 9. Flash Patched Image
In your command terminal inside the `platform-tools` directory, run:

```bash
fastboot flash boot <magisk_patched_filename.img>
```

> **Note:** The filename generated by Magisk differs each time. Enter your actual generated file name.

### 10. Reboot Device
When the terminal outputs `OKAY`, the file is flashed. Reboot with:

```bash
fastboot reboot
```

![Terminal flashing output confirmation](/images/a39401275d1b300.png)
*Terminal flashing output confirmation*


### 11. Verify Root
Once the phone boots, open Magisk. If the Magisk version is displayed, Root is successfully activated!

![Magisk successfully verified](/images/33e75ff09dd601b.jpg)
*Magisk successfully verified*

## Troubleshooting & Tips

<details>
<summary>waiting for any device</summary>

If fastboot hangs on `waiting for any device`, see the [waiting for any device guide](/magisk/troubleshooting/waiting-for-device).
</details>

:::tip[Recovery Instructions (Emergency Restore)]
If your phone fails to boot or gets stuck in a bootloop after flashing:
1. Power off and hold **Power + Volume Down** to return to Fastboot mode.
2. Flash your unmodified stock backup image:
   ```bash
   fastboot flash boot boot.img
   ```
3. Run `fastboot reboot`. Normal startup will be restored immediately with no data loss.
:::
